Sources & how this works

Architecture

This is a local dashboard, not a public website. It runs a tiny Node server on your own computer (server.js, started by start.bat) that reads and writes 🎓 OMSCS Backlog.md straight in your Obsidian vault folder on disk — the same pattern as your rock-n-roll-expenses dashboard. Nothing leaves your computer.

The page polls /api/state every 5 seconds, so edits you make in Obsidian normally show up here within a few seconds. Clicking a checkbox here does the reverse — it edits that exact line in the vault file immediately (only that one line; nothing else in the file is touched) and Obsidian will pick it up the next time you look at the file.

Your morning-briefing Todoist/Slack skill reads the same vault file independently — so this dashboard, Obsidian, and your morning briefing are always looking at the same, single source of truth. The skill also ignores Todoist's own "completed" state for these tasks specifically — the vault checkbox is what decides done vs. not-done, so checking something off here or in Obsidian is what actually stops the nagging, not checking off the Todoist card.
